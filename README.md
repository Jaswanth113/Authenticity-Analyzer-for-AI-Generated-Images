# AI Image Detection


This is the **Flask-based backend** for the [Image-Detection-UI](https://github.com/Jaswanth113/Image-Detection-UI) project an AI-powered tool that classifies images as **AI-generated** or **real** using **Error Level Analysis (ELA)** and a trained **TensorFlow** model.

## Features

- Detects whether an image is AI-generated or authentic.
- Uses **ELA preprocessing** + **ResNet50V2 deep learning** for classification.
- Flask REST API backend serving predictions from a trained TensorFlow model.
- Integrates with a [Vite + React frontend](https://github.com/Jaswanth113/Image-Detection-UI) for seamless UI-based image analysis.
